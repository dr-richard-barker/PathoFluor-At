# PathoFluor-At

**Fluorescence hyperspectral imaging of *Arabidopsis* seedlings challenged with *Pseudomonas syringae*
or flg22 (Col-0, *fls2*, *cml24*): a FAIR reanalysis of the 2016 UW-Madison experiment.**

## What this is

In July 2016 seedlings of five genotypes were imaged in the Gilroy Lab (UW-Madison Botany) with a
MacroPhor fluorescence hyperspectral imager (488 nm excitation, 500–800 nm emission). The genotypes
were Col-0, *fls2-17*, *fls2-101*, *cml24-2* and *cml24-4*. Imaging was done before and 1, 2, 3, 24 and
48 h after treatment with a mock solution, flg22 or *P. syringae* (the method, planned as flood inoculation, is still to be confirmed). An independent replicate
followed in November 2016 (405 nm excitation; Col-0 and the two *fls2* lines). This repository
recovers that experiment from its original drive, documents every data problem, and tests:

1. Is there a hyperspectral fluorescence signature of bacterial challenge, and how early?
2. Is there a signature of flg22 perception? If so, it must be absent in the *fls2* receptor mutants.
3. Does loss of the Ca²⁺ sensor CML24 change either signature?

## Findings so far (from `tables/`, regenerated by the scripts)

- **The 2016 summaries' intensity drop after treatment is an exposure artefact.** Exposure time changed
  between timepoints. Divided by exposure, Control intensity at 1–3 h is within 4% of hour 0
  (`tables/fig1_exposure_artefact.csv`).
- **Plates differed before treatment.** At hour 0 a classifier separates flg22 from Control plates
  perfectly, so only change from each plate's own baseline is used as evidence (`tables/model_auc.csv`).
- **Some 2016 exports kept the dark level.** 83 hand-ROI spectra (all on Pathogen plates) were
  saved without dark subtraction, which mimics broad autofluorescence. Every spectrum is corrected by
  its own emission below the 488 nm excitation line (`results/roi_import_report.md`).
- **Early pathogen signature.** Relative to baseline, *P. syringae* broadens the red chlorophyll emission
  peak from 1 h to 24 h and raises 500–640 nm emission from 2 h
  (`tables/stats_contrasts_baseline_adjusted.csv`). Change-from-baseline spectra separate infected from
  control plates at 1, 2 and 24 h (plate-level AUC 1.0, exact permutation p = 0.029). At 24 h the
  short-wavelength rise is smaller in *cml24-4* in the hand ROIs (q = 0.036), but this did not
  replicate at seedling level.
- **Seedling-level replication.** 1,623 seedlings segmented from the raw July cubes reproduce the early
  signature, independently of the 2016 annotations. Exposure-corrected 685 nm emission then falls, and
  seedlings shrink by 48 h (`tables/seedling_stats.csv`). Bacteria-only scans do not fluoresce
  (`tables/setb_control_scans.csv`).
- **The set-A flg22 signal is not FLS2-dependent.** A Col-0-trained model scores *fls2* plants as
  strongly as Col-0, so the signal is a plate-level effect, not perception
  (`tables/model_specificity.csv`).

## Repository layout

| Path | Contents |
|---|---|
| `scripts/00_inventory.py` … `09_site_data.py` | Numbered, idempotent, resumable pipeline (see below) |
| `src/pathofluor/` | ENVI reader, file-name parsers, features, segmentation |
| `metadata/` | `file_inventory.csv` (all 7,752 drive files, SHA-256), `cube_manifest.csv` (every cube's acquisition settings), `roi_manifest.csv`, `FACTS_PENDING.md`, `related_material.md`, `study.yaml` |
| `data/original_2016/` | The 2016 hand-ROI spectra, ENVI headers, summary graphs and pilot material, copied unchanged (raw cubes excluded) |
| `results/` | Derived per-ROI and per-seedling tables, per-cube QC, label validation |
| `tables/` | Statistics, model performance and per-figure source tables |
| `figures/` | Figures (PNG + PDF) and `CAPTIONS.md` |
| `manuscript/` | LaTeX manuscript; `numbers.tex` is generated, so no result is typed by hand |
| `slides/` | Beamer deck built from the same figures and numbers |
| `docs/` | GitHub Pages site (CoSE theme) with an interactive spectrum explorer |

## Reproduce

```bash
python3 -m venv .venv && .venv/bin/pip install -r requirements.txt
export PATHOFLUOR_SRC="/path/to/Hyperspectral_UW-Botany_July 2016"   # raw drive or the Zenodo archives
.venv/bin/python scripts/00_inventory.py          # manifests (raw-cube hashes filled in after step 2)
.venv/bin/python scripts/01_import_rois.py        # hand-ROI spectra -> shape features
.venv/bin/python scripts/02_harvest_cubes.py      # one pass over the raw cubes (~3 h on USB)
.venv/bin/python scripts/03_segment_seedlings.py
.venv/bin/python scripts/04_assign_labels.py
.venv/bin/python scripts/05_stats.py
.venv/bin/python scripts/06_models.py
.venv/bin/python scripts/07_numbers.py && .venv/bin/python scripts/08_figures.py
.venv/bin/python scripts/09_site_data.py
make -C manuscript draft && make -C slides
```

Steps 01 and 05–09 need only the files in this repository. Steps 02–04 need the raw cubes.

## Data availability

The raw cubes (about 396 GB) are too large for GitHub. They are packed as 33 lossless tar.zst archives
(155.7 GB, grouped by set x hour x treatment, plus the bacteria-only and reference scans) for four Zenodo records. Every member of every archive was
decompressed and checked against the SHA-256 in `metadata/cube_manifest.csv`. The record plan and the
archive SHA-256 values are in `metadata/zenodo_records.csv`. DOIs are pending upload. Everything else is here. The 2016 Middleton Spectral Vision analysis reports are cited and
summarised (`metadata/related_material.md`) but not redistributed.
